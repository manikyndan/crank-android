## ✨ Features

- 🏠 Home feed with trending music
- 🔍 Search across artists, albums, and tracks
- ▶️ Background playback with lock-screen / headset controls (Media3)
- ⬇️ Offline downloads with quality selection
- ❤️ Library: Liked Songs, playlists, history
- 🎤 Karaoke-synced lyrics & song recognition
- 🌙 Luxurious dark theme (gold on obsidian) + light mode

## 🛠️ Build from source

```bash
git clone https://github.com/manikyndan/crank-android.git
cd crank-android
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/Crank Music.apk
```

Requirements: JDK 17, Android SDK (compileSdk 37).
